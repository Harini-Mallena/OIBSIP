# Retail Sales Exploratory Data Analysis

## Objective

The objective of this project is to analyze retail sales data and
identify useful patterns in sales trends, customer demographics,
product performance, and customer spending.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data inspection and cleaning
- Missing value and duplicate analysis
- Descriptive statistics
- Monthly sales trend analysis
- Quarterly sales trend analysis
- Customer age-group analysis
- Gender distribution analysis
- Top 10 best-selling products
- Revenue by product category
- Correlation analysis and heatmap
- Average transaction amount by age group

## Key Insights

- Price per Unit has a strong positive correlation with Total Amount.
- Quantity has a moderate positive relationship with Total Amount.
- Age has very weak relationships with the sales-related variables.

## Business Recommendations

1. Focus on high-revenue product categories.
2. Maintain sufficient inventory for best-selling products.
3. Use age-based marketing strategies.
4. Analyze product pricing to improve transaction value.
