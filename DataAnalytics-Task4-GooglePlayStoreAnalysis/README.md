
# Google Play Store Data Analysis 📱

## 📌 Project Overview
This project analyzes Google Play Store data to understand app categories, ratings, installs, pricing, and user review sentiment. The main objective is to discover trends in app popularity and user feedback using Python and data visualization.

## 🎯 Objectives
- Analyze the distribution of apps across categories.
- Explore app ratings and average ratings by category.
- Compare free and paid apps.
- Analyze the price distribution of paid apps.
- Investigate the relationship between app size and installs.
- Perform sentiment analysis on user reviews.
- Identify categories with the highest installs and positive or negative sentiment.

## 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VADER Sentiment Analysis

## 📊 Analysis Performed
1. App Category Distribution
2. Distribution of App Ratings
3. Average Rating by Category
4. App Size vs. Number of Installs
5. Free vs. Paid Apps Analysis
6. Price Distribution of Paid Apps
7. User Review Sentiment Analysis
8. Categories with the Most Positive Sentiment
9. Categories with the Most Negative Sentiment
10. Total App Installs by Category

## 💡 Key Insights
- The Game category recorded the highest total installs, followed by Communication.
- Positive sentiment was the most common sentiment in the analyzed user reviews.
- Social apps showed the highest negative sentiment, followed by Video Players and Entertainment.
- Comics ranked highest for positive sentiment in the category comparison.
- Free apps significantly outnumbered paid apps.
- Paid app prices were highly right-skewed, with a few expensive outliers.
- App size and installs showed a weak positive correlation of approximately 0.169.

## ✅ Conclusion
The analysis highlights differences in app popularity, pricing, ratings, and user sentiment across categories. Games and Communication attracted high install volumes, while sentiment analysis revealed categories where user feedback may deserve closer attention. These insights can help developers better understand app-market trends and potential areas for improvement.
